# Captures de Pantalla per a la Documentació

Aquest directori està destinat a allotjar les captures de pantalla visuals per a [`DOCUMENTACIO_PROJECTE.md`](file:///e:/Dashboard/DOCUMENTACIO_PROJECTE.md).

## Recomanacions de Format i Mida
- **Format**: PNG optimitzat o WebP / JPG (qualitat 80-85%).
- **Resolució màxima recomanada**: 1280 px d'amplada (per mantenir una mida d'arxiu lleugera, entre 100 KB i 200 KB per imatge).
- **Privadesa**: Assegurar que no es mostrin dades bancàries o personals excessivament sensibles.
